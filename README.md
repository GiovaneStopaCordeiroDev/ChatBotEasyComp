# ChatBot-EasyComp

# Sobre o Projeto

Projeto da faculdade de chatbot. Desenvolvimento de uma API ASP.NET Core para integração com a OpenAI e WhatsApp Business API, permitindo o desenvolvimento de um assistente virtual para a escola de informática de bauru EasyComp.

# Tecnologias
C#
ASP.NET Core (.NET 10)
OpenAI API
Swagger
Git/GitHub

# Funcionalidades
Receber perguntas através da API.
Gerar respostas utilizando Inteligência Artificial.
Validar e receber mensagens via Webhook do WhatsApp.
Documentação automática com Swagger.
